Install Harkenn on a speaker

Harkenn is a private voice assistant for your home: small speakers that listen and answer, and a server you run yourself. This page puts the speaker firmware on a Spotpear ESP32-S3 1.28" BOX, straight from your browser.

Before you start

  1. Use Chrome or Edge on a computer (they can talk to USB devices; Firefox and Safari can't).
  2. Connect the speaker with a USB-C data cable.
  3. Installing erases the speaker, including the XiaoZhi firmware it comes with. There's no going back from this page, so back it up first if you might want it.

Install

Your browser can't do this: use Chrome or Edge on a computer. This page has to be opened over https.

Then

  1. The speaker starts a Wi-Fi network called Harkenn-XXXX. Join it with your phone and pick your home Wi-Fi on the page that opens (or go to 192.168.4.1).
  2. It finds your Harkenn server and shows a 3-digit code. Enter it on the server's admin page to adopt it.

No server yet? See server-docker. The firmware is speaker-firmware.
